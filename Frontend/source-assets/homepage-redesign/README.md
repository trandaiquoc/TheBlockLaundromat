# Homepage redesign source artwork

This directory stores approved, standalone source artwork for the new asset-first Homepage redesign. It is separate from the existing four-theme scene assets in Frontend/source-assets/homepage/ and is not connected to the app build or preview yet. Figma assembly is planned for Phase 4.

Generation candidates and rejected rounds remain in the ignored local .artifacts/homepage-redesign/ directory. Only approved artwork belongs here.
