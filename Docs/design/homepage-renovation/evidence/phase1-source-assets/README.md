# Source Package Evidence — Phase 1

Files in this directory were supplied inside the source ZIP and are preserved
as provenance evidence. `design-qa.md`, `VALIDATION.json`, and
`BROWSER-EXPORT-VALIDATION.json` report checks performed by the asset-package
author; they are not tests of the current Angular application.

All 37 preview files were copied without modification. The Minecraft, Light,
and Dark `*-source-comparison.png` previews have incomplete PNG data and are
not viewable. The complete source references and layer PNGs are separately
validated and preserved under
`Frontend/source-assets/homepage/`.

The source package's standalone HTML/JS/Python demo was intentionally not
copied here or into production. The temporary `.02-light.png.ycYBQF` reference
is excluded and described in
[`../../source-assets/PROVENANCE.md`](../../source-assets/PROVENANCE.md).
