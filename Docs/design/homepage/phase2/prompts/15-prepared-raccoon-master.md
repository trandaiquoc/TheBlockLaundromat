PHASE 3 — RACCOON MASTER 01
PREPARED ONLY AFTER PHASE 2 CLOSEOUT

Create ONE raccoon master asset for The Block Laundromat.

This is the first production-oriented mascot master.
Generate a single full-body raccoon on a transparent background.

Use the reference images as follows:

- Image A is desktop-concept-v2.png. It is the approved desktop composition and the primary reference for the raccoon's integrated identity, material language, line quality and color behavior in the room.
- Image B is portrait-concept-v7.png. It confirms the same raccoon identity in the approved portrait concept.
- Image C is the selected sword-post raccoon reference.
- Image D is the selected autumn sleeping raccoon reference.
- Image E is the selected string raccoon reference.

Use Images C, D and E to preserve the chosen stylistic family:
rounded silhouette, soft irregular dark-brown outlines, cream / gray-olive / warm-brown body shapes, simple rounded eye masks, small compact paws, striped tail, restrained grain and diffuse shading.

Do NOT copy any exact prop, costume, accessory or pose from the real references.

GOAL
Create the clean master version of the original project raccoon used in the approved concept scenes.

OUTPUT

- One image only
- Transparent background required
- True alpha transparency
- No background color
- No floor
- No props
- No text
- No logo
- No decorative frame
- No cast environment
- No watermark

CANVAS
Use a portrait-oriented canvas.
Recommended output ratio: 4:5
Recommended size: 1600 × 2000 or equivalent high-resolution 4:5 ratio.

Place the raccoon fully inside frame with comfortable padding on all sides.
No body part may be cropped.

POSE
Create a neutral “master” pose suitable for reuse:

- full-body standing pose
- slight 3/4 view
- head turned slightly toward viewer’s left
- gentle curious expression
- both paws visible and slightly raised in front of the body
- tail visible and curved naturally to one side
- feet clearly visible
- ears fully visible
- body balanced and readable

The pose should feel close in spirit to the approved washer-side scene character, but cleaned into a reusable standalone master pose.

STYLE

- Hand-drawn illustration
- Matte finish
- Soft irregular dark-brown outlines
- Diffuse shading
- Very light grain only
- No glossy highlights
- No plastic 3D look
- No painterly over-rendering
- No vector-flat oversimplification

COLOR + FORM

- Cream muzzle/belly highlights
- Gray-olive / soft taupe main fur body
- Warm-brown eye mask and tail stripes
- Dark-brown outline
- Compact rounded paws
- Large simple friendly eyes
- Small nose and mouth
- Rounded head and torso
- Cute but not babyish to the point of losing identity
- Keep proportions aligned with the approved concept raccoon, not a different mascot design

EDGE / TRANSPARENCY REQUIREMENTS
This is critical:

- clean true-alpha cutout
- no white halo
- no dark fringe
- no colored matte edge
- no fake transparency artifacts
- no background remnants
- no semi-opaque box
- no baked drop shadow
- no floor shadow unless it is a separate extremely subtle isolated shape fully compatible with transparency; prefer no shadow at all

IDENTITY REQUIREMENTS
The result must clearly match the raccoon identity already established in desktop-concept-v2 and portrait-concept-v7:

- same general face proportions
- same eye-mask logic
- same tail stripe logic
- same paw shape language
- same overall softness and silhouette

Do not drift into:

- hyper-detailed fur rendering
- anime redesign
- plush toy styling
- shiny mascot branding style
- generic stock raccoon look

ACCEPTANCE CRITERIA
PASS only if:

1. The raccoon is a clean standalone reusable master asset.
2. Background is transparent with true alpha.
3. Edges are clean with no halo or fringe.
4. The design clearly matches the approved desktop and portrait concept identity.
5. The pose is neutral, stable and reusable.
6. All limbs, tail, ears and paws are fully visible.
7. No props, no text, no logo, no environmental objects are included.
8. The rendering remains matte, hand-drawn and stylistically consistent with the approved concept art.

Generate exactly one raccoon master asset only.
