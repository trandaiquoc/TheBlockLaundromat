ROOT CAUSE TO SOLVE

Previous edits tried to widen a blank wall while
preserving the left shelves, right structural column,
foliage and existing room boundaries.

Those constraints prevented a reliably sized
logo-safe region.

Stop attempting to solve this by moving shelves
slightly farther apart.

Instead, introduce one physically supported
architectural sign backing with a measured,
unobstructed front face.

DESIGN SOLUTION

Add ONE blank oak-framed cream-plaster brand plaque,
suspended from the existing upper wooden ceiling beam.

The plaque belongs to the room architecture.

It is NOT:

- a UI header,
- a dashboard panel,
- a floating card,
- a generated logo,
- a decorative sticker.

It must resemble a believable hanging sign
constructed from wood and cream-painted material.

POSITION AND SIZE

Coordinates below refer to the intended
390 × 1150 CSS composition.

Target plaque outer bounds:

x = 45..345
y = 115..285

Approximate outer size:
300 × 170 CSS px.

The frame should contain a visibly flat,
front-facing cream surface.

REQUIRED CLEAN INTERIOR

Minimum unobstructed inner rectangle:

260 × 140 CSS px.

Keep this interior calm and almost perfectly frontal.

The existing brand logo will later be inserted
independently at:

200–220 CSS px wide,
100–110 CSS px high,
original aspect ratio preserved.

The logo must fit without touching frame edges,
plants, shadows, hangers or decorations.

Make the plaque's actual clean face large enough.

Do not compensate by shrinking the intended logo.

PHYSICAL SUPPORT

Use two clearly visible suspension points,
such as dark metal hangers, short chains or
wooden brackets.

Connect BOTH supports to the existing
upper wooden ceiling beam.

Ensure:

- believable attachment positions,
- plausible structural weight,
- consistent perspective,
- appropriate contact and cast shadows,
- no unexplained floating attachment.

Keep the plaque near-frontal.

Very mild illustrated perspective is acceptable,
but its front surface must remain suitable for
a later independent logo layer.

OCCLUSION POLICY

The plaque MAY naturally cover:

- portions of the existing cream wall,
- minor wall shadows,
- partial upper shelf edges,
- small decorations behind the plaque,
- limited background foliage.

This is intentional.

Do not preserve every old architectural contour
when doing so prevents the plaque from fitting.

Keep occlusion physically logical.

The plaque must clearly sit in front of the
background wall and behind no foreground object
that would obstruct the logo.

ARCHITECTURAL INTEGRATION

Use the same:

- honey oak material,
- dark-brown hand-drawn outlines,
- warm cream painted surfaces,
- subtle grain,
- diffuse shading,
- upper-left daylight,
- soft lower-right cast shadows

as portrait v4 and desktop v2.

The frame must not become glossy,
photorealistic or visually oversized.

It must feel manufactured from materials
already present in this room.

TOP CONTROLS

Preserve a small usable zone near the viewport's
top edge for future global settings/language/theme
controls.

Do not draw these controls.

Do not position the plaque over the complete
top-control safe area.
