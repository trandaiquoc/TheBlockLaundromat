PHASE 3 — PRIMARY PROJECT PANEL MASTER 01
SPLIT ASSET METHOD / CLEAN GENERATION

PROJECT
The Block Laundromat — Illustrated Interactive Homepage.

TASK

Generate ONE standalone landscape wooden project panel.

Create ONLY:

- one broad cream-colored rectangular face,
- one surrounding honey-oak wooden frame,
- simple corner joints and small hardware.

Do NOT create legs, support posts, braces, a desk,
a floor, or any environment.

This is a reusable production panel master.
Its structural supports will be separate assets.

REFERENCES

1. desktop-concept-v2.png
   Primary board identity and material reference.

2. portrait-concept-v7.png
   Shared cream-face and oak-frame visual language.

3. washer-master-v1.png
   Approved production material, texture and camera.

4. raccoon-master-v1.png
   Approved outline softness and illustration style.

Do not use any earlier failed board candidate
as a visual reference.

CRITICAL DESIGN

The panel must be a broad LANDSCAPE rectangle.

It must have a generous cream interior.

Do not make the panel extremely wide and shallow.

Do not make it square or portrait.

The cream face should have an approximate
width-to-height ratio of 1.45 to 1.50.

The wooden frame must be narrow relative to
the usable face.

Keep its top, bottom, left and right rails
approximately balanced.

Avoid oversized bottom rails.

GEOMETRY

Think of the finished panel as approximately:

- 100 units wide,
- 75 units tall.

Within that outer panel, reserve a clean cream face
approximately:

- 90 units wide,
- 61 units tall.

These values describe the panel itself,
NOT the image canvas.

The clean interior is the dominant part
of the asset.

Preserve a nearly frontal rectangular shape.

The panel must be suitable for later scaling
to a desktop width of approximately 660 CSS px.

At that scale, the clean cream face must support
a fully contained UI rectangle measuring at least:

560 CSS px wide
355 CSS px high

The usable UI rectangle must fit within the
cream surface with positive padding on all sides.

Do not reduce the intended UI size.

Do not distort or stretch the final PNG.

CAMERA

Near-frontal 2.5D illustration.

- Upright vertical edges.
- Horizontal upper and lower rails.
- Minimal perspective distortion.
- Slight frame thickness is acceptable.
- No isometric view.
- No exaggerated perspective convergence.

STYLE

Match the approved Light-theme art direction:

- warm honey oak,
- soft cream interior,
- dark-brown irregular outlines,
- matte painted surfaces,
- restrained wood grain,
- subtle paper-like texture,
- diffuse shading,
- upper-left daylight,
- gentle lower-right form shading.

The frame should appear physically constructed
rather than being a generic digital UI border.

FRAME DETAILS

Use simple, restrained construction:

- four wooden rails,
- credible corner joints,
- a few small fasteners if necessary.

Keep the interior completely unobstructed.

Do not add extra decorative borders inside
the cream face.

No clips, pins, shelves or handles overlapping
the clean surface.

TRANSPARENCY

Produce genuine RGBA transparency.

The background OUTSIDE the panel must have
alpha 0.

The cream face must be opaque.

The oak frame must be opaque.

No checkerboard texture.
No painted transparency.
No white or black background.
No rectangular background residue.
No halo or dark fringe.
No baked cast shadow.

CANVAS

Use a landscape-oriented transparent canvas.

Recommended resolution:
1600 × 1200 pixels.

The panel should occupy most of the canvas
with sufficient transparent padding.

The canvas aspect ratio is NOT the panel's
required aspect ratio.

Preserve the actual panel geometry.

STRICT EXCLUSIONS

No legs.
No support posts.
No braces.
No workstation.
No floor.
No wall.
No plants.
No shelves.
No lantern.
No washing machine.
No raccoon.
No logo.
No text.
No numbers.
No project cards.
No buttons.
No thumbnails.
No search interface.
No decorative content inside the cream face.

ACCEPTANCE

PASS only when:

1. The result contains exactly one framed panel.

2. The clean cream face is approximately
   1.45–1.50 times wider than it is tall.

3. The face is near-frontal, readable and
   geometrically stable.

4. When uniformly scaled to approximately
   660 CSS px outer width, the face can contain
   a real 560 × 355 CSS px UI rectangle.

5. The UI rectangle has positive padding
   on every side.

6. The frame is restrained and does not
   consume excessive usable height.

7. Materials match approved production masters.

8. Outside the panel is true transparent alpha.

9. Face and frame remain opaque.

10. No fake checkerboard, halo or background.

11. No legs, support structures or environment.

12. No baked UI, text or project thumbnails.

OUTPUT

Generate exactly ONE standalone panel master PNG.

Do not generate a supported board.
Do not generate a portrait workstation.
Do not generate additional variants.

Prioritize clean usable surface geometry,
consistent art style and true transparency.
