# Check-authored washer master01 prompt

After independent raccoonv1 PASS. References: approved desktopv2, portraitv7 and raccoonv1. This is the active next Phase3 job; not a room or animationparts approval.

PHASE 3 — WASHER MASTER 01

PROJECT
The Block Laundromat — Illustrated Interactive Homepage.

TASK
Generate ONE standalone production washing-machine master
on a genuine transparent background.

This is a foundational production asset, not a room
composition, UI mockup or animated sprite sheet.

REFERENCES

1. desktop-concept-v2.png
   Primary reference for the washing machine's identity,
   silhouette, perspective, proportions and materials.

2. portrait-concept-v7.png
   Reference for mobile composition, washer dimensions,
   circular door geometry and physical placement.

3. raccoon-master-v1.png
   Approved mascot master for cross-asset consistency
   in outlines, colors, grain, shading and scale.

IDENTITY

Recreate the original sage-and-cream washing machine
established in the approved concepts.

Preserve:

- Rounded rectangular body.
- Warm cream front enamel.
- Muted sage-green accents and lower trim.
- Large circular front-loading door.
- Sage-colored circular door frame.
- Door handle on the viewer's right.
- Compact top control area.
- Dark round control dial.
- Small simple indicator controls.
- Rounded illustrated construction.
- Subtle visible side panel.

The machine must be recognizable as the same model
from desktop v2 and portrait v7.

Do not invent a different washing-machine design.

CAMERA

Nearly frontal 2.5D camera.

- Upright body verticals.
- Front face nearly parallel to image plane.
- Slightly visible top and right side.
- Modest downward viewing angle.
- Mild perspective only.
- Circular door remains visually circular.
- No isometric or dramatic wide-angle distortion.

Match the camera family of both concept scenes.

STYLE

Use the exact established illustration language:

- Hand-drawn matte surfaces.
- Soft irregular dark-brown outlines.
- Warm cream and muted sage enamel.
- Restrained paper-like grain.
- Diffuse shading.
- Gentle upper-left illumination.
- Consistent edge and texture density.
- Simplified but credible material construction.

Match raccoon-master-v1 visually.

Avoid:

- photorealism,
- glossy 3D rendering,
- PBR materials,
- metallic chrome effects,
- heavy gradients,
- excessive highlights,
- ultra-thin technical vector outlines.

CROSS-ASSET SCALE

The washer must fit beside the approved raccoon.

In scene coordinates:

- washer should read approximately 1.6–1.9 times
  the raccoon's standing height,
- washer body should be substantially wider
  than the raccoon's torso,
- washer door should be large enough to become
  the principal visual focus.

Use physical proportions consistent with
desktop-concept-v2 and portrait-concept-v7.

Do not use the transparent image's canvas dimensions
as the measure of physical scale.

Preserve the washer's grounded base and complete
lower silhouette for later scene composition.

DYNAMIC PROJECT PREVIEW APERTURE

CRITICAL REQUIREMENT:

The central washing-machine door must support
a real dynamic project thumbnail later.

Create a clean, regular circular opening.

Preferred construction:

- Door frame/rim remains opaque.
- Door handle remains opaque.
- Machine body remains opaque.
- The inner circular preview aperture is true alpha 0
  if technically achievable.
- Aperture edge must be clean and smooth.
- No project preview is painted inside.

The aperture should be nearly frontal and must not
have perspective deformation that prevents a simple
circular runtime mask.

If a genuine transparent aperture cannot be produced
reliably, do not simulate transparency using a
checkerboard or painted background.

Instead keep a plain neutral interior and flag the
need to create the aperture through a verified alpha
mask during production processing.

Do not compromise the machine silhouette or rim
merely to fake transparency.

REFLECTIONS

Do not bake strong reflections across the preview
aperture.

Any door-glass reflection should later be created
as a separate optional transparent overlay.

For this master, preserve only the opaque door frame,
handle and body.

No painted example Minecraft project.

ASSET BOUNDARIES

The entire machine must be visible.

Include:

- full top,
- side panel,
- both lower corners,
- base,
- complete circular door,
- handle,
- all machine controls.

Provide sufficient transparent padding around
the complete silhouette.

No cropped or missing hidden-edge geometry.

Do not include:

- folded towels,
- plants,
- lanterns,
- crates,
- shelves,
- platforms,
- flooring,
- walls,
- environment shadows,
- the raccoon,
- extra washing machines.

These are independently owned scene assets.

TRANSPARENCY

True RGBA output.

- Transparent exterior.
- Alpha 0 outside machine.
- No painted background.
- No checkerboard.
- No white matte.
- No dark halo.
- No visible edge fringe.
- No baked floor shadow.
- No semi-transparent rectangular residue.

The washer must work over light, dark and illustrated
backgrounds without visible edge contamination.

OUTPUT

One high-resolution PNG with transparent background.

Recommended canvas:
1600 × 1600 pixels or equivalent square resolution.

Keep the entire machine comfortably within the canvas.

Maintain adequate padding without unnecessarily
shrinking the actual machine.

No text, logo, watermark or asset-sheet labels.

ACCEPTANCE CRITERIA

PASS requires:

1. Same recognizable washer identity as desktop v2
   and portrait v7.

2. Correct near-frontal 2.5D perspective.

3. Cross-asset style consistency with raccoon-master-v1.

4. Warm cream body, sage accents and matte finish.

5. Correct round door, right-side handle and
   compact upper controls.

6. Clean usable circular preview aperture.

7. Transparent aperture preferred; if not possible,
   clearly identifiable neutral area suitable
   for subsequent alpha-mask processing.

8. No baked project thumbnail or door-glass reflection.

9. Complete machine silhouette and clean edges.

10. Genuine transparent exterior with no visible halo.

11. No unrelated environment objects or shadows.

12. Suitable for later independent compositing,
    responsive placement and animation overlays.

Generate exactly ONE washer master asset.
Do not generate multiple variants, a sprite sheet
or an assembled room.
