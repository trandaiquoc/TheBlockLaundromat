PHASE 3 — PORTRAIT WORKSTATION MASTER 01

PROJECT
The Block Laundromat — Illustrated Interactive Homepage

TASK

Generate ONE standalone portrait workstation asset
with a large clean vertical project-board facade.

This workstation belongs to the approved mobile
Light-theme composition.

It must provide a shared horizontal top surface
for the separately composited washing machine
and raccoon.

The front facade contains a large clean cream
surface for real dynamic UI.

This is NOT a desktop board resized into portrait.

PRIORITY

1. Geometry guide.
2. Usable UI dimensions.
3. Physically supported workstation construction.
4. Approved material and illustration language.
5. Decorative details.

STRUCTURE

Create one connected wooden workstation.

It contains:

- a broad horizontal wooden tabletop,
- a large vertical cream project-board facade
  beneath the tabletop,
- an illustrated honey-oak frame,
- side posts and credible structural connections,
- lower support ends for ground contact.

The tabletop must be visibly connected to the
wooden structure below it.

The front facade must be physically part of
the workstation, not a separate floating panel.

The entire object must share one coherent
near-frontal 2.5D camera.

CRITICAL UI GEOMETRY

The intended responsive composition is
390 CSS px wide.

The workstation is approximately 370 CSS px
wide within this composition.

Provide a clean board-face region large enough
for a real 330 × 290 CSS px UI rectangle.

Prefer approximately 340 × 300 CSS px of
clean cream surface when feasible.

The usable surface must be:

- near-frontal,
- rectangular,
- flat,
- unobstructed,
- softly textured,
- low contrast.

Do not divide it into decorative cards.

Do not make it excessively wide and shallow.

Do not copy the landscape aspect ratio of the
approved desktop panel.

The facade needs enough vertical space
for a one-column project interface.

At narrower viewports, the future interface
will reflow and scroll naturally.

Do not achieve responsive fit by stretching
or nonuniformly scaling the artwork.

WORKSTATION TOP

The top must be sufficiently broad and stable
to support two separately placed objects:

1. The approved sage washing machine.
2. The approved raccoon standing beside it.

Both must share the SAME horizontal top surface.

Their contact points must align with this surface.

Do not draw either object into the workstation.

Do not generate fake silhouettes or placeholders
representing those objects.

Keep the top surface visually clean.

Its front edge must connect naturally to the
frame of the board facade.

STRUCTURAL GROUNDING

Include credible vertical supports.

Ensure all visible posts and braces are connected.

Keep bottom contact ends complete.

Do not generate a floor.

The final room composition will place these
supports on the existing illustrated floor.

Do not create a second independent platform
or a second floor plane.

PERSPECTIVE

Near-frontal illustrated 2.5D.

- Upright verticals.
- Mild tabletop visibility.
- Slight side thickness.
- No exaggerated isometric projection.
- No strong perspective convergence.
- No wide-angle distortion.

The cream UI face must remain almost frontal.

MATERIALS

Match the approved production assets.

Honey-oak structural wood.
Warm cream board surface.
Dark-brown irregular outlines.
Subtle hand-drawn wood grain.
Restrained paper-like texture.
Matte material finish.
Soft diffuse shading.

Lighting:
warm daylight from upper-left,
subtle form shading toward lower-right.

Keep the workstation visually compatible with
the washer, raccoon and desktop panel.

UI-SAFE REGION

Leave the cream facade entirely blank.

It is reserved for future real UI including:

- project search,
- sorting,
- one-column project list,
- create/import access,
- selected project states.

These requirements describe future functionality.

DO NOT DRAW THE UI.

No:

- text,
- project names,
- thumbnails,
- icons,
- buttons,
- cards,
- sample data,
- decorative panels inside the cream face.

Keep corner hardware outside the usable UI area.

TRANSPARENCY

Generate a real RGBA PNG.

Outside the workstation silhouette:
alpha must be transparent.

Wooden surfaces and cream board face:
opaque.

No checkerboard pattern.

No painted background.

No room environment.

No white or dark halo.

No rectangular background residue.

No baked floor shadow.

All physical edges must be complete.

STRICT ASSET OWNERSHIP

Include only the workstation structure.

DO NOT include:

- washing machine,
- raccoon,
- plants,
- towels,
- laundry baskets,
- lanterns,
- shelves,
- wall,
- window,
- exterior scenery,
- floor,
- logo,
- UI,
- lettering.

These are independent scene assets.

OUTPUT

One high-resolution standalone transparent PNG.

Use a canvas large enough for the full object.

The object should occupy most of its canvas
with modest transparent padding.

Preserve the geometry guide's proportions.

Do not stretch the finished PNG.

Do not generate an assembled room or multiple
design variations.

ACCEPTANCE

PASS only when:

1. The workstation forms one connected structure.

2. A single broad top surface supports future
   washer and raccoon placement.

3. The front board face is part of the same
   physical workstation.

4. The face can contain a real 330 × 290 CSS px
   UI rectangle at the intended 390px layout.

5. The clean face remains unobstructed.

6. The board is not a scaled desktop panel.

7. Support posts connect correctly and have
   complete lower contact ends.

8. No secondary platform or floor is created.

9. Camera and material language match the
   approved Light-theme production masters.

10. Exterior alpha is genuinely transparent.

11. No checkerboard or edge contamination.

12. No washer, raccoon, props, room or floor.

13. No generated UI, text or project data.

14. All edges and contacts are complete.

Generate exactly ONE portrait workstation master.
